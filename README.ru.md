# AgoraBoard - доска объявлений и рынок обменов

[English version: README.md](README.md)

**Общая доска для игроков сервера: объявления, безопасные обмены предметов через депозит, деньги в обменах и публикация в чат - всё через удобное меню.**

Работает на **Paper, Folia и Spigot**, Minecraft **1.18.2 - 26.3**, Java 17+. Подходит для ванильных, выживательных и экономических серверов: в чате больше нет спама «продам алмазы» и нет обманутых игроков.

---

## Возможности

### Объявления
- Игроки создают объявления по категориям (категории, иконки и названия задаются в конфиге).
- Срок жизни (по умолчанию **10 дней**), лимит на игрока (по умолчанию **2**), длина текста и запрещённые слова настраиваются.
- Меню с постраничным просмотром, фильтром по категориям и режимом «мои объявления».
- Клик по чужому объявлению подсказывает, как связаться с автором (команда `/msg` настраивается). Клик по своему открывает управление: повторная публикация в чат или удаление.

### Обмены с депозитом (режим GUI)
- Укажите, что вам **нужно** (один предмет, любое количество, даже больше стака), и что вы **отдаёте** (несколько предметов с количеством, **деньги** или всё вместе), плюс необязательное описание (зачарования, условия).
- Предметы и деньги, которые вы отдаёте, забираются на доску при создании обмена. Обмануть никого нельзя: если у принимающего есть нужное, обмен проходит сам прямо из меню.
- Владелец получает уведомление (сразу или при заходе), а оплату забирает в отдельном окне «получить предметы». Ничего не пропадёт, если инвентарь полон или игрок не в сети.
- При отмене, истечении срока или удалении модератором предметы **и зарезервированные деньги** возвращаются владельцу.
- **Договорные** обмены: напишите `negotiable` (или `договорная`) вместо предложения. Это обычное объявление, ничего не списывается, договариваются игроки сами.
- **Режим NATURAL** (по желанию): доска только показывает обмены, ничего не удерживается и не обменивается автоматически.
- Иконка в списке - предмет, который **нужен** владельцу, поэтому сразу видно, что вы можете выполнить. Поиск по предмету: `/board find`.
- Лимит по умолчанию - **5** обменов на игрока (настраивается).

### Деньги (Vault)
- **Деньги вместо предметов или вместе с ними**: `/board trade diamond 5 money 250`. Минимум и максимум суммы настраиваются.
- Деньги списываются (резервируются) при создании обмена, возвращаются при отмене, истечении срока или удалении и сразу выплачиваются принявшему обмен.
- Необязательные **цены** на размещение объявлений, обменов и публикацию в чат. Цена `0` - бесплатно, и стоимость нигде не показывается.
- Работает с любым плагином экономики через **Vault** (EssentialsX, CMI и другие). Без Vault плагин работает, просто цены и деньги в обменах отключены.

### Публикация в чат
- Добавьте `-c` к команде (или нажмите кнопку в меню), чтобы объявить в общий чат. Опубликовать повторно можно в любой момент.
- Бесплатная публикация имеет общий кулдаун (по умолчанию **30 мин** на все объявления игрока), платная - цену и без кулдауна.
- Дружит с плагинами чата, выберите подходящий режим:
  - `BROADCAST` - плагин сам отправляет оформленное сообщение с кликабельными кнопками (работает везде),
  - `COMMAND` - выполняет ваши команды от имени консоли (`broadcast` из EssentialsX, ChatControl и др.),
  - `PLAYER` - отправляет текст от имени игрока, чтобы плагин чата применил свои форматы и правила.

### Все тексты настраиваются
- Все сообщения, заголовки меню, кнопки и **префикс плагина** лежат в `lang/<язык>.yml` (формат MiniMessage: цвета, градиенты, подсказки, клики).
- В комплекте **русский и английский** языки. Чтобы добавить свой, скопируйте файл и переведите его.
- `/board admin reload` применяет изменения без перезапуска.

### Права на всё
Отдельные права на каждую команду, создание листингов, публикацию в чат, **удаление чужих объявлений и обменов** и **публикацию чужих листингов в чат**. У модераторов в меню на чужих листингах работает «Shift + ПКМ».

### Сделан для современных серверов
- Один jar для **Paper, Folia (безопасно для потоков регионов) и Spigot**.
- Данные в простом YAML-файле, сохранение без лагов. Логика обмена «всё или ничего»: без дюпов и потерянных предметов.
- Лёгкий: база данных не нужна, обязательных зависимостей нет.

## Команды

| Команда | Описание |
|---|---|
| `/board` (`/agora`, `/doska`) | Главное меню |
| `/board ads` / `/board trades` | Список объявлений / обменов |
| `/board ad [-c] <категория> <текст>` | Создать объявление (`-c` - ещё и в чат) |
| `/board trade [-c] <нужное> [кол-во] <отдаёте> <кол-во> ... [money <сумма>] [описание]` | Создать обмен |
| `/board trade <нужное> [кол-во] negotiable [описание]` | Создать договорной обмен |
| `/board find <предмет>` | Найти обмены, где нужен предмет |
| `/board claim` | Забрать предметы, которые вам причитаются |
| `/board help` | Справка |
| `/board admin <reload, list, remove, selftest>` | Администрирование (`remove <ad или trade> <id>`) |

Пример: `/board trade diamond 5 iron_ingot 64 money 250 Без зачарований`

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `agoraboard.use` | все | Открыть доску и её меню |
| `agoraboard.command.help` / `ads` / `trades` / `find` / `claim` | все | Соответствующая команда (`agoraboard.command.*` - все сразу) |
| `agoraboard.ad` / `agoraboard.trade` | все | Создавать объявления / создавать и принимать обмены |
| `agoraboard.chat` | все | Публиковать свои листинги в чат |
| `agoraboard.chat.others` | оп | Публиковать в чат чужие листинги |
| `agoraboard.remove.ad` / `agoraboard.remove.trade` | оп | Удалять чужие объявления / обмены (`agoraboard.remove.*` - оба) |
| `agoraboard.admin.reload` / `list` / `selftest` | оп | Соответствующая подкоманда `/board admin` |
| `agoraboard.admin` | оп | Все админ-команды, удаление и публикация чужих листингов |
| `agoraboard.unlimited` | оп | Без лимитов, кулдаунов и цен |

## Быстрая настройка

```yaml
language: ru            # ru, en или свой файл в lang/
trade-mode: GUI         # GUI - автоматический обмен через депозит, NATURAL - только показ
message-command: msg    # команда для кнопок «связаться»
notify-on-join: true    # сводка по доске при входе
ads:    { max-per-player: 2, duration-days: 10, price: 0 }
trades: { max-per-player: 5, duration-days: 10, price: 0, money: { enabled: true, min: 1, max: 0 } }
chat:   { enabled: true, mode: BROADCAST, price: 0, cooldown-minutes: 30 }
```

## Установка
1. Положите `AgoraBoard.jar` в папку `plugins/`.
2. (По желанию) Установите **Vault** и плагин экономики для цен и денег в обменах.
3. Запустите сервер, отредактируйте `plugins/AgoraBoard/config.yml` и `lang/`, затем выполните `/board admin reload`.

## Совместимость
- Paper, Folia и Spigot, **1.18.2 - 26.3**, Java 17 и новее.
- Проверено на живых серверах: Paper 1.18.2 / 1.20.4 / 1.21.4 / 26.3, Folia 1.20.4 / 26.2 и Spigot 1.20.4 автоматической самопроверкой (`/board admin selftest`). Остальные версии диапазона проверены по API сервера.
- Необязательно: Vault и любой плагин экономики.
- Предметы, сохранённые на Paper, не читаются на Spigot и наоборот. Не переносите файл данных между типами серверов, пока есть активные обмены.

## Статистика
AgoraBoard использует [bStats](https://bstats.org/plugin/bukkit/AgoraBoard/34636) для анонимной статистики (версия сервера, режим обмена, язык). Её можно отключить в `plugins/bStats/config.yml`.

## Сборка

```bash
mvn package
```
Результат: `target/AgoraBoard-<версия>.jar` (Java 17+).
